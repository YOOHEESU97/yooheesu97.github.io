# 투자 공부 콘텐츠 운영 계획

## 정체성과 독자

> 직장인이 ISA·연금·ETF로 자산을 관리하면서, 미국 시장과 AI 산업을 이해하도록 돕는 콘텐츠

- 독자: 투자와 절세계좌를 처음 공부하는 직장인.
- 약속: 공식 원문에 근거해 쉽게 설명하고, 확인된 사실·나의 해석·아직 모르는 점을 구분한다.
- 범위: 개인의 학습과 정보 제공. 개인별 매수·매도 판단이나 수익 보장을 대신하지 않는다.
- 기존 개발 글은 유지한다. 투자 글은 `investing` 카테고리에 모으고 서로 이어지는 시리즈로 쓴다.

## 확장 순서

### 1단계: 기본 글 (첫 1~2개월)

주 2편을 목표로 하되 조사와 검증이 끝난 글만 발행한다. 순서는 독자의 질문에 맞춰 조정할 수 있다.

1. ISA는 어떤 계좌인가: 계좌의 목적과 확인할 조건
2. 연금저축은 어떤 계좌인가: 목적, 납입, 인출 시 확인할 점
3. ISA와 연금저축을 비교할 때 볼 항목
4. ETF란 무엇인가: 지수·구성 종목·추적 방식
5. ETF를 고를 때 볼 항목: 보수·추적 차이·환율·거래량
6. 나스닥 종합지수와 나스닥100은 무엇이 다른가
7. 미국 지수 ETF를 읽는 방법: 기초지수와 환노출 확인
8. 정책이 바뀔 때 기존 글을 확인하고 고치는 방법

세율, 한도, 가입 자격 등은 작성 시점의 국세청·금융위원회·금융투자협회 등 공식 자료로 확인한다. 확인하지 못한 수치는 글에 쓰지 않는다.

### 2단계: 실제 사례

- 엔비디아 투자 노트를 출발점으로 실적 발표에서 확인할 숫자를 읽는다.
- AI 반도체 기업과 관련 ETF의 연결은 구성 종목·비중·기준일을 확인한 뒤 설명한다.
- 새 기사는 1단계 기본 글과 연결한다. 전망에는 반론과 틀릴 조건을 함께 적는다.

### 3단계: 정책과 시사

- ISA·연금·세금 정책과 시장 이슈 중 기존 독자의 질문에 답하는 주제만 다룬다.
- 발표일, 시행일, 적용 대상, 예외를 구분한다. 시행 전 내용은 확정된 제도처럼 쓰지 않는다.
- 제도가 바뀌면 관련 기존 글을 수정하고 수정일을 표시한다.

## AI별 역할과 바로 쓸 요청문

### Gemini — 자료 수집

> 주제: [글 주제]. 국세청·금융위원회·금융투자협회 등 공식 원문을 우선 찾아줘. 주장마다 원문 URL, 발표일, 적용 시점, 원문의 해당 문구 또는 표 위치를 적어줘. 확인되지 않은 내용은 별도 목록으로 빼고 추측하지 마.

기업·시장 글은 기업 IR/공시, 지수·ETF 발행사 자료, 한국은행 ECOS 등을 주제에 맞게 추가한다. AI가 제시한 링크와 숫자는 직접 열어 다시 확인한다.

### GPT — 이해, 초안, 반론

> 아래에 붙인 검증된 원문 메모만 근거로 초보 직장인을 위한 글의 목차와 초안을 만들어줘. 각 단락을 '확인된 사실 / 나의 해석 / 불확실한 점'으로 구분해줘. 투자 결론을 단정하지 말고, 독자가 헷갈릴 용어와 빠진 반론을 찾아줘. 출처에 없는 숫자나 링크를 만들지 마.

초안이 나오면 별도 검토를 요청한다: “이 글에서 근거가 약한 문장, 시점이 빠진 숫자, 독자를 오해하게 할 제목을 표시해줘.”

### Cursor — 블로그 구현과 게시 전 검사

> 검증이 끝난 원고를 이 Astro 저장소의 `src/content/blog/` 형식에 맞게 추가해줘. 투자 카테고리, 실제 발행일, 원문 링크, 관련 글 링크를 확인하고 모바일에서 표·긴 링크가 넘치지 않는지 검사해줘. `npm run build`를 실행하고 변경 파일 목록과 결과를 보여줘. 사실관계나 날짜를 임의로 수정하지 마.

Cursor가 파일을 작성해도 최종 글과 Git diff는 사람이 읽는다. 실제 게시 시각만 `publishedAt`에 적고 과거 시각을 임의로 만들지 않는다.

## 글 한 편의 공통 구조

1. 독자가 가진 질문과 이 글의 범위
2. 세 줄 요약
3. 원자료로 확인된 핵심 사실과 기준일
4. 쉬운 설명 또는 비교 사례
5. 내 해석과 다른 해석이 가능한 부분
6. 확인할 위험·예외·변경 가능성
7. 원문 출처와 확인일, 관련 글 링크

## 발행 전 체크

- 숫자, 세율, 제도 조건, ETF 구성과 수익률의 기준일을 기록했는가?
- 원문 링크를 실제로 열어 수치와 문장을 대조했는가?
- 사실과 개인 의견을 분리했는가? 특정 상품·종목을 사라고 단정하지 않는가?
- 제목이 본문보다 더 강한 주장을 하지 않는가?
- 모바일에서 표와 링크가 읽히고 빌드가 성공하는가?

## 채널 확장 기준

- **블로그:** 기본 개념과 출처가 남는 원본 글을 쌓는다.
- **유튜브:** 독자의 질문이 반복되는 글부터 자신의 설명·도표·사례를 넣어 영상화한다. 글을 AI 음성으로 그대로 읽는 방식은 피한다.
- **네이버 프리미엄 콘텐츠:** 무료 글을 통해 독자가 계속 묻는 구체적인 문제를 확인한 뒤, 원자료 비교·지속 갱신·심화 사례처럼 구독할 이유가 있는 형식을 시험한다.

조회수만 보지 말고 어떤 글을 다시 읽는지, 어떤 질문이 이어지는지, 원문 검증과 갱신을 지속할 수 있는지 함께 살핀다.
